Curator's icon is a stack of knowledge cards with a four-point sparkle in mint and teal.
`icon.svg` is the self-contained vector source; `icon.png` is its transparent 256px rendering for Paseo's PNG-only manifest icon field. Both ship in the package. See the [project README](../README.md).

`native-routing-settings.png` (1060 × 212) and `native-routing-providers.png` (1060 × 330)
are real native Paseo settings captures. The second has a marked redaction over local
installation details. See [capture provenance](../docs/screenshots/README.md). Both are
manifest media and ship with the package; no raw full-window captures are included.
